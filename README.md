## Как это работает

Сервер запускается на одном компьютере (обычно это ноутбук главного судьи). Все остальные открывают нужные страницы в браузере по IP-адресу сервера: судьи команд — с телефонов, хронометрист — со своего устройства, а компьютер, подключённый к LED-панели, — страницу табло.

```
 Ноутбук главного судьи                       Компьютер у панели
┌────────────────────────┐  Wi-Fi или кабель  ┌──────────────────┐
│ server.js              │◄──────────────────►│ браузер          │
│ браузер: /adminpanel   │   http://IP:порт   │ /display         │──► LED-панель
└────────────────────────┘                    └──────────────────┘
        ▲        ▲
        │        └── телефон хронометриста: /timer
        └── телефоны судей команд: /controller
```

| Страница | Кто пользуется | Что делает |
|---|---|---|
| `/` | все | вход по PIN-коду: пользователя автоматически отправляет на нужную страницу |
| `/adminpanel` | главный судья | всё: таймер, команды, PIN-коды, оформление, эстафета, генератор ссылок |
| `/controller` | судья команды | крупный счётчик +1 / −1 только для своей команды и её название |
| `/timer` | хронометрист | только время: старт, пауза, сброс, режим, длительность |
| `/display` | компьютер у панели | только картинка для панели, без кнопок |

- Все изменения мгновенно появляются на всех открытых табло. Подключить можно несколько.
- Часы компьютеров разные, поэтому таймер считается по времени сервера, а страницы подстраиваются под него. Несколько табло всегда показывают одно и то же время.
- Состояние живёт на сервере. Страницы отправляют ему команды и рисуют то, что он присылает (Server-Sent Events, дополнительных пакетов не нужно).
- Когда время вышло, сервер сам останавливает таймер, и все экраны видят одно и то же.

## Быстрый старт

Нужен [Node.js](https://nodejs.org) (версия LTS). Установка пакетов не требуется.

**На компьютере главного судьи:**

```bash
node server.js
```

В консоли будут показаны PIN-коды и адреса. Админ-панель открывается на этом же компьютере по `http://localhost/`, затем вводится PIN администратора.

**На компьютере у панели:**

1. Откройте в браузере адрес табло из консоли или админ-панели, например `http://192.168.1.10/display` (Chrome, Edge).
2. Нажмите `F` или дважды щёлкните по экрану: табло развернётся на весь экран.

> Если панель подключена прямо к ноутбуку как второй монитор, достаточно открыть `http://localhost/display` в отдельном окне, перетащить его на панель и нажать `F`.

## Запуск и порт

По умолчанию сервер слушает порт **80**. Если порт занят или нет прав (Linux, macOS), укажите другой:

```bash
node server.js --port=8080
node server.js --port=8080 --pin=4242     # заодно задать PIN администратора
```

Те же параметры можно передать переменными окружения: `PORT=8080 ADMIN_PIN=4242 node server.js`. Если порт не 80, он указывается в адресах: `http://IP:8080/display`.

## Сеть

- Все устройства должны быть **в одной сети**: общий Wi-Fi, роутер или кабель. Интернет не нужен. Подойдёт и точка доступа на телефоне.
- При первом запуске Windows спросит про доступ Node.js к сети: разрешите **частные сети**.
- Если страница не открывается по IP: проверьте, что устройства в одной сети (в гостевых Wi-Fi устройства часто изолированы друг от друга), и что брандмауэр разрешает Node.js.
- На компьютере у панели отключите спящий режим и экранную заставку.

## PIN-коды и роли

Роль определяется по PIN-коду, который вводится на главной странице `/`:

| PIN | Куда ведёт | Как получить |
|---|---|---|
| администратора | `/adminpanel` | по умолчанию `1234`; задаётся `--pin=` или `ADMIN_PIN`, меняется в админ-панели |
| команды | `/controller` | у каждой команды свой, виден в её карточке в админ-панели |
| хронометриста | `/timer` | один на всех, виден в админ-панели |

PIN команды и хронометриста генерируются автоматически (4 цифры) и не совпадают между собой и с PIN администратора; любой можно заменить новым одной кнопкой. Код запоминается в браузере. Табло смотреть может любой, а управлять — только тот, кто знает код. **Смените PIN администратора по умолчанию**, если в сети есть посторонние.

## Возможности

- ⏱ **Таймер** — обратный отсчёт (по умолчанию 10:00) или секундомер, время с точностью до секунды (от 0:10 до 99:59)
- 👥 **До 8 команд** — у каждой свой PIN, счёт до 999, названия, цвета и огранка
- 🧑‍⚖️ **Судьи и хронометрист** — каждый видит и меняет только своё
- 🏃 **Командная эстафета** — общее время делится на участников, результаты каждого выводятся на табло, в конце общий итог
- 🥇 **Счёт лидера** — на табло одной команды показывается счёт лидера
- 🧭 **Положение подсказок** — счёт предыдущих участников эстафеты и счёт лидера можно разместить сверху, снизу, слева или справа от основного счётчика
- 🔗 **Настройка табло через адрес** и **генератор ссылок** с предпросмотром
- 📐 **Любая форма панели** — раскладка (столбиком, рядом или сеткой) подбирается так, чтобы цифры были крупнее
- 🔍 **Под низкое разрешение** — крупные цифры без сглаживания, градиентов и тонких линий
- ⭕ **Скруглённые цифры и рамка** — мягкая форма без полутонов, чёткая на любом разрешении
- 🎨 **7 цветовых схем** и ручная настройка каждого цвета
- 🔴 **Тревога** — последние 10 секунд и конец времени красным; на паузе и по окончании времени таймер мигает
- 💾 **Запоминает настройки** — время, режим, цвета, команды и их PIN-коды хранятся в `settings.json` рядом с `server.js`

## Табло одной команды и ссылки с настройками

`/display` показывает все команды. `/display?team=3` показывает только команду с номером 3 (номер виден в её карточке и в генераторе ссылок). На таком табло дополнительно выводится счёт лидера («ЛИДЕР» и число); по умолчанию он стоит снизу, положение меняется в админ-панели (см. ниже), а сам показ отключается галочкой.

Любые настройки оформления можно передать в адресе, и они будут действовать только на этом табло, перекрывая общие:

| Параметр | Значение |
|---|---|
| `team` | номер команды (табло одной команды) |
| `pal` | номер цветовой схемы, 0–6 |
| `timer` `frame` `line` `alarm` `t1` `t2` | цвета таймера, рамки, линий, тревоги, нечётных и чётных команд; hex без `#`, например `timer=ffffff` |
| `nameColor` `countColor` `edge` | цвета названия, счёта и огранки команд |
| `names` `leader` `frame` `round` | `1` или `0`: названия, счёт лидера, рамка, скруглённые цифры |
| `legsPos` `leaderPos` | положение счёта предыдущих участников эстафеты и счёта лидера относительно основного счётчика: `top`, `bottom`, `left`, `right` |

Пример: `http://192.168.1.10/display?team=2&pal=2&names=0&leaderPos=right`.

Порядок приоритета цветов: настройки сервера → схема из адреса → цвета табло этой команды из её карточки → отдельные цвета из адреса.

Проще всего не собирать адрес вручную, а воспользоваться секцией **«Генератор ссылок для табло»** в админ-панели: она собирает адрес по выбранным параметрам, показывает предпросмотр заданного размера панели и даёт кнопки «Копировать» и «Открыть». Предпросмотр не считается подключённым табло.

## Командная эстафета

Включается в админ-панели (под таймером), пока таймер сброшен. Режим работает только с обратным отсчётом.

- Задайте общее время (например, 6:00) и число участников в команде (2–6). Время на каждого считается само: 6:00 на троих — по 2:00.
- Судья считает как обычно, кнопками +1 и −1.
- Когда время этапа заканчивается, результат участника уходит в ячейку команды рядом с основным счётом. По умолчанию это строка над счётом, например `5 8 -`; если выбрать положение слева или справа, результаты встают столбиком, по одному участнику на строку. Прочерк стоит у тех, кто ещё не толкал.
- Счёт следующего участника начинается **с нуля** или **продолжается с текущего количества** — выбирается в панели.
- Когда общее время вышло, видны результаты всех участников, а основной счёт показывает общую сумму. После этого счёт не меняется.
- «Сбросить таймер» в этом режиме обнуляет и результаты, и счётчики. На странице судьи в статусе пишется «этап 2 из 3».

## Управление с клавиатуры

Клавиши работают в админ-панели, если курсор не в поле ввода (Enter или Esc возвращают управление).

| Клавиша | Действие |
|---|---|
| `Пробел` / `Enter` | старт / пауза |
| `1` … `8` | команда с этим номером: +1 (`Shift` — −1) |
| `←` / `→` | время ±1 мин (`Shift` — ±10 с), пока таймер не запущен |
| `R` | сбросить таймер |
| `Delete` | обнулить все счётчики |
| `T` | обратный отсчёт / секундомер |
| `C` | следующая цветовая схема |

На странице хронометриста работают `Пробел`/`Enter`, `R`, `T` и стрелки. На странице судьи команды — `Пробел`/`↑`/`Enter` (+1) и `↓`/`Backspace` (−1). На странице табло — `F` и двойной щелчок (полный экран).

`R` и `Delete` работают только когда таймер не идёт, чтобы случайно не стереть результат посреди подхода. Время и режим меняются только до старта. Клавиши работают при любой раскладке.

## Названия команд

- до 14 символов; буквы переводятся в заглавные
- поддерживаются русские и латинские буквы, цифры и знаки ` - . , ' ! + : / ( )`, остальное отбрасывается
- название можно менять в админ-панели и на странице судьи команды
- если название не помещается по ширине панели, оно обрезается, а админ-панель показывает предупреждение; если места нет совсем, название скрывается
- галочка «Показывать названия команд на табло» отключает их целиком, и тогда всё место отдаётся цифрам

## Цвета и оформление

**Табло.** Первая схема — «ТГАСУ»: малиновая команда 1 (фирменный E5007D), синяя команда 2, синяя рамка и разделитель, белый таймер. Когда время вышло, рамка загорается красным. Любой цвет можно поменять вручную: рамка, линии, таймер, цвета нечётных и чётных команд, тревога. Для отдельной команды в её карточке настраиваются цвета названия, счёта и огранки (цветная рамка вокруг её ячейки на общем табло), а также цвета всего табло этой команды.

| Настройка | Что делает |
|---|---|
| Скруглённые цифры и рамка | цифры рисуются штрихами с круглыми концами, углы рамки скруглены; на совсем маленьких панелях лучше вернуть классический вид |
| Рамка вокруг табло | тонкая рамка по краю; отнимает несколько пикселей, на маленьких панелях её можно отключить |
| Названия команд | показ и скрытие названий над счётом |
| Счёт лидера | показ счёта лидера на табло одной команды |
| Счёт предыдущих участников эстафеты | где выводить результаты участников: сверху (по умолчанию), снизу, слева или справа от основного счётчика |
| Счёт лидера: положение | где выводить счёт лидера: снизу (по умолчанию), сверху, слева или справа от основного счётчика |

Выбор готовой схемы сбрасывает индивидуальные цвета команд.

**Положение подсказок.** Оба списка находятся в админ-панели в блоке «Табло», а для отдельного табло их можно задать в адресе (`legsPos`, `leaderPos`) или в генераторе ссылок. Если обе подсказки выбраны с одной стороны, они ставятся рядом: ближе к краю результаты участников, затем счёт лидера. Основной счёт занимает оставшееся место.

**Пульт.** Тёмно-синий фон, малиновые акценты и кнопки. В шапке страниц можно показать логотип университета: положите файл `logo.png` в папку `sites` (если файла нет, картинка скрывается).

> **О цветах.** Малиновый `#E5007D` взят как заданный фирменный цвет. Синий подобран под светодиоды: тёмно-синий на чёрном фоне панели почти не виден, поэтому для табло использован более яркий оттенок. Чтобы заменить цвета, поправьте блок `:root` в начале `sites/adminpanel/index.html` (оформление пульта) и первую схему в списке `PALETTES` в `sites/render.js` (табло).

### Цветовые схемы

| № в `pal=` | Схема |
|---|---|
| 0 | ТГАСУ: малиновый и синий |
| 1 | Классика: янтарь, зелёный, голубой |
| 2 | Огонь и лёд: оранжевый и синий |
| 3 | Неон: розовый и бирюзовый |
| 4 | Всё янтарным — для монохромных панелей |
| 5 | Всё зелёным — для монохромных панелей |
| 6 | Всё красным — для монохромных панелей |

Клавиша `C` в админ-панели перебирает схемы по кругу.

## Как выглядит раскладка

Приложение само выбирает сетку, где цифры получаются крупнее (в столбик, в ряд или квадратом). Неполный последний ряд центрируется.

```
Вертикальная панель          Горизонтальная панель
┌──────────┐                 ┌──────────────────────┐
│  10:00   │                 │        10:00         │
├──────────┤                 ├──────────┬───────────┤
│  ДИНАМО  │                 │  ДИНАМО  │ ЛОКОМОТИВ │
│    42    │                 │    42    │    37     │
├──────────┤                 └──────────┴───────────┘
│ЛОКОМОТИВ │
│    37    │
└──────────┘
```

Размер табло определяется по окну браузера на компьютере у панели: сколько пикселей у окна, на столько и рисуется картинка. Админ-панель видит этот размер подключённых табло и предупреждает, если названия не помещаются.

## Устройство проекта

```
├── server.js              сервер: состояние, таймер, роли и PIN-коды, раздача страниц, обмен в реальном времени
├── settings.json          создаётся сам: сохранённые настройки, команды и PIN-коды
└── sites/
    ├── render.js          отрисовка табло, пиксельный шрифт, цветовые схемы (общий для сервера и страниц)
    ├── net.js             связь страниц с сервером и синхронизация часов
    ├── index/             страница входа по PIN
    ├── adminpanel/        пульт главного судьи и генератор ссылок
    ├── controller/        страница судьи команды
    ├── timer/             пульт хронометриста
    ├── display/           страница табло
    └── logo.png           (необязательно) логотип для шапки страниц
```

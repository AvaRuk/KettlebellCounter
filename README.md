## Как это работает

Оператор работает на ноутбуке, а табло открывается в браузере на любом компьютере в той же сети. Именно этот компьютер подключён к LED-панели.

```
 Ноутбук оператора                          Компьютер у панели
┌──────────────────┐   Wi-Fi или кабель   ┌──────────────────┐
│ server.js        │◄────────────────────►│ браузер          │
│ браузер: /control│   http://IP:3000     │ /display         │──► LED-панель
└──────────────────┘                      └──────────────────┘
```

- **Пульт** (`/control`) — время, счёт, названия, цвета, превью табло в реальном разрешении.
- **Табло** (`/display`) — только картинка для панели, без кнопок.
- Все изменения мгновенно появляются на всех открытых табло. Подключить можно несколько.
- Часы компьютеров разные, поэтому таймер считается по времени сервера, а табло подстраивается под него. Несколько табло всегда показывают одно и то же время.
- Если связь на секунду пропадёт, табло продолжит считать время само, а при возвращении связи догонит счёт.

## Быстрый старт

Нужен [Node.js](https://nodejs.org) (версия LTS). Установка пакетов не требуется.

**На ноутбуке оператора:**

1. Дважды щёлкните по `start.bat` (или выполните `node server.js`).
2. Откроется пульт: `http://localhost:3000/control`. В окне консоли и в самом пульте будет показан адрес табло, например `http://192.168.1.10:3000/display`.

**На компьютере у панели:**

1. Откройте этот адрес в браузере (Chrome, Edge).
2. Нажмите `F` или дважды щёлкните по экрану: табло развернётся на весь экран.

Для автоматического запуска на весь экран скопируйте на тот компьютер `display-kiosk.bat`, запустите его и введите IP ноутбука.

> Если панель подключена прямо к ноутбуку как второй монитор, достаточно открыть `http://localhost:3000/display` в отдельном окне, перетащить его на панель и нажать `F`.

## Сеть

- Оба компьютера должны быть **в одной сети**: общий Wi-Fi, роутер или кабель. Интернет не нужен. Подойдёт и точка доступа на телефоне.
- При первом запуске Windows спросит про доступ Node.js к сети: разрешите **частные сети**.
- Если табло не открывается по IP: проверьте, что компьютеры в одной сети (в гостевых Wi-Fi устройства часто изолированы друг от друга), и что брандмауэр разрешает Node.js.
- Порт по умолчанию 3000. Другой порт: `node server.js --port=3001`.
- На компьютере у панели отключите спящий режим и экранную заставку.

## Защита PIN-кодом

В сети с посторонними (зрители, общий Wi-Fi) задайте PIN. Тогда табло смотреть может любой, а управлять только тот, кто знает код.

```bash
node server.js --pin=4242
```

Пульт запросит код при первом действии и запомнит его в браузере. Через `start.bat` код передаётся так же: `start.bat --pin=4242`.

## Возможности

- ⏱ **Таймер** — обратный отсчёт (по умолчанию 10:00) или секундомер; время задаётся с точностью до секунды
- 👥 **Две команды** — свои цвета и клавиши, счёт до 999
- ✏️ **Названия команд** — вводятся в пульте и сразу появляются на табло пиксельным шрифтом (кириллица, латиница, цифры)
- 📐 **Любая форма панели** — раскладка подбирается автоматически под вертикальные, квадратные и горизонтальные панели
- 🔍 **Под низкое разрешение** — крупные цифры без сглаживания, градиентов и тонких линий
- 🎨 **Тема ТГАСУ** — малиновый E5007D и синий на табло и в пульте
- ⭕ **Скруглённые цифры и рамка** — мягкая форма без полутонов, чёткая на любом разрешении
- 🔴 **Тревога** — последние 10 секунд и конец времени красным; на паузе таймер мигает
- 💾 **Запоминает настройки** — время, режим, цвета и названия хранятся в `settings.json` рядом с сервером

## Как выглядит раскладка

Приложение само выбирает вариант, где цифры получаются крупнее.

```
Вертикальная панель          Горизонтальная панель
┌──────────┐                 ┌──────────────────────┐
│  10:00   │                 │        10:00         │
├──────────┤                 ├──────────┬───────────┤
│  ДИНАМО  │                 │  ДИНАМО  │ ЛОКОМОТИВ │
│    42    │                 │    42    │    37     │
├──────────┤                 └──────────┴───────────┘
│ЛОКОМОТИВ │
│    37    │
└──────────┘
```

Размер табло определяется по окну браузера на компьютере у панели: сколько пикселей у окна, на столько и рисуется картинка. Пульт видит этот размер и показывает превью один в один. Если табло ещё не подключено, превью можно посмотреть для типовых размеров панелей (список «Размер превью»).

## Управление

Клавиши работают на странице пульта, если курсор не в поле ввода (Enter или Esc возвращают управление).

| Клавиша | Действие |
|---|---|
| `Пробел` / `Enter` | старт / пауза |
| `Q` / `A` &nbsp;(или `Num7` / `Num1`) | команда 1: +1 / −1 |
| `P` / `L` &nbsp;(или `Num9` / `Num3`) | команда 2: +1 / −1 |
| `←` / `→` | время ±1 мин (`Shift` — ±10 с), пока таймер не запущен |
| `R` | сбросить таймер |
| `Delete` | обнулить оба счёта |
| `T` | обратный отсчёт / секундомер |
| `C` | цветовая схема |

На странице табло работают только `F` и двойной щелчок (полный экран).

`R` и `Delete` работают только когда таймер не идёт, чтобы случайно не стереть результат посреди подхода. Время и режим меняются только до старта. Клавиши работают при любой раскладке.

## Названия команд

- до 14 символов; буквы переводятся в заглавные, `Ё` выводится как `Е`
- поддерживаются русские и латинские буквы, цифры и знаки ` - . , ' ! + : / ( )`, остальное отбрасывается
- если название не помещается по ширине панели, оно обрезается, а пульт покажет предупреждение; если места нет совсем (очень маленькая панель), название скрывается
- галочка «Показывать названия команд на табло» отключает их целиком, и тогда все место отдаётся цифрам

## Цвета и оформление

**Табло.** Первая схема — «ТГАСУ»: малиновая команда 1 (фирменный E5007D), синяя команда 2, синяя рамка и разделитель, белый таймер. Когда время вышло, рамка загорается красным. Есть схемы «Классика», «Огонь и лёд», «Неон» и три монохромных (янтарь, зелёный, красный) для одноцветных панелей. Любой цвет можно поменять вручную: рамка, таймер, команда 1, команда 2, тревога.

| Настройка | Что делает |
|---|---|
| Скруглённые цифры и рамка | цифры рисуются штрихами с круглыми концами, углы рамки скруглены; на совсем маленьких панелях можно вернуть классический вид |
| Рамка вокруг табло | тонкая рамка по краю; отнимает несколько пикселей по краям, на маленьких панелях её можно отключить |
| Названия команд | показ и скрытие названий над счётом |

**Пульт.** Тёмно-синий фон, малиновые акценты и кнопки, цвета команд берутся из выбранной схемы табло. В шапке пульта можно показать логотип университета: положите файл `logo.png` рядом с `server.js`.

> **О цветах.** Малиновый `#E5007D` взят как заданный фирменный цвет. Синий подобран под светодиоды: тёмно-синий на чёрном фоне панели почти не виден, поэтому для табло использован более яркий оттенок. Чтобы заменить цвета, поправьте блок `:root` в начале `control.html` (оформление пульта) и первую схему в списке `PALETTES` в `render.js` (табло).

### Цветовые схемы

| № | Схема |
|---|---|
| 1 | ТГАСУ: малиновый и синий |
| 2 | Классика: янтарь, зелёный, голубой |
| 3 | Огонь и лёд: оранжевый и синий |
| 4 | Неон: розовый и бирюзовый |
| 5 | Всё янтарным — для монохромных панелей |
| 6 | Всё зелёным — для монохромных панелей |
| 7 | Всё красным — для монохромных панелей |

Клавиша `C` перебирает схемы по кругу.

## Устройство проекта

```
├── server.js         сервер: состояние, таймер, раздача страниц, обмен в реальном времени
├── render.js         отрисовка табло, шрифты, цветовые схемы, клавиши (общий для сервера и страниц)
├── net.js            связь страниц с сервером и синхронизация часов
├── control.html/js   пульт оператора
├── display.html/js   страница табло
├── start.bat         запуск сервера и пульта на ноутбуке
├── display-kiosk.bat запуск табло на весь экран на компьютере у панели
├── logo.png          (необязательно) логотип для шапки пульта
└── package.json
```

Состояние (счёт, время, режим) живёт на сервере. Страницы только отправляют ему команды и рисуют то, что он присылает (технология Server-Sent Events, дополнительных пакетов не нужно).

Табло

    Общее табло (все команды) — откройте в браузере на компьютере у панели. Табло отдельной команды — ссылка в её карточке

    На том компьютере нажмите F или дважды щёлкните по экрану — табло развернётся на весь экран.

    Цвета общего табло

    У каждой команды свой цвет. Цвета названия, счёта, огранки (цветная рамка вокруг ячейки команды на общем табло) и всего табло отдельной команды (адрес с ?team=) настраиваются в её карточке. Тревога — цвет таймера в последние 10 секунд; по окончании времени рамка тоже становится этого цвета. На очень маленьких панелях скругление лучше отключить.

    Генератор ссылок для табло

    Настройки из ссылки действуют только на то табло, где она открыта, и перекрывают общие настройки. Отмеченное галочкой попадает в адрес, остальное берётся из настроек сервера.

    Открыть

    Параметры адреса: team (номер команды), цвета timer frame line alarm nameColor countColor edge (hex без #, например timer=ffffff), переключатели names leader frame round (0 или 1), положение счёта участников эстафеты и лидера legsPos leaderPos (top bottom left right).

    Доступ

    Судьи команд и хронометрист входят на главной странице сервера: судья команды — по PIN из карточки своей команды, хронометрист — по PIN ниже.

    Пульт хронометриста: только таймер (старт, пауза, сброс, время и режим), счёт команд ему доступен для просмотра.
